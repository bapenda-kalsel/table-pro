Deterministic Execution

Read the exact SQL before it touches your data

Staged edits translate into standard, parameterized SQL statements you can inspect line by line.

Approve the batch to commit atomically, or discard to leave your database untouched.

-- staged changes on employees (3 operations)
BEGIN TRANSACTION;

UPDATE "employees"
SET "salary_usd" = 9200
WHERE "id" = 42;

INSERT INTO "employees" ("employee_name", "department", "salary_usd")
VALUES ('Ayu Pratama', 'Revenue Analytics', 8450);

DELETE FROM "employees" WHERE "id" = 7;

COMMIT;
