Features

Built like a workbench, not a toy

Staged changes workflow

Inline edits, inserts, and deletes are buffered locally with color-coded highlighting. Review the generated SQL in a diff modal, then commit everything in one atomic transaction.

Keychain security

Passwords live in the OS keychain, never in config files. Production-tagged connections require confirmation for writes.

SQL editor

CodeMirror 6 with live schema autocomplete, explain plans, and result export.

ER diagram

Reverse-engineers every table and foreign key into a draggable visual map.

Audit trail

Every query persisted with stats, filtering, and CSV or JSON export.

Power tools included

Global text search across all columns, CSV import, VACUUM and backup maintenance, saved snippets, visual table designer, and a quick switcher. The UI speaks English and Bahasa Indonesia.

See the SQL before it runs

Staged edits are translated into real statements you can read first. Nothing hidden, nothing surprising.

Approve the batch and it commits atomically. Reject it and your database stays untouched.

-- staged changes on employees (3 operations)
BEGIN TRANSACTION;

UPDATE employees
SET salary = 7200
WHERE id = 42;

INSERT INTO employees (name, role)
VALUES ('Ayu Pratama', 'Analyst');

DELETE FROM employees WHERE id = 7;

COMMIT;
